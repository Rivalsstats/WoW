Methodology & caveats
  • Every spec is simulated in one SimulationCraft batch on a single simc build, so all rows in a tab are directly comparable. Fights use the Patchwerk fight style at 1, 3, 5 and 8 targets (switch with the tabs above). Fight length is tuned per target count: single-target fights run 3 minutes to settle cooldown cycles, while the multi-target fights (3, 5 and 8 targets) run 1 minute to reflect the shorter bursts of AoE pulls.
  • Popular is the spec's most-popular Mythic+ gear set — the same items, enchants, gems and talent loadout shown on its spec page.
  • SimC BIS is the highest-DPS full gear set our collector finds by evaluating thousands of legal gear combinations built from items actually equipped in high Mythic+ runs (tier configurations co-optimised, embellishment and unique-equipped limits enforced), worn with those same popular talents. A spec shows an em dash for this set until it has been BiS-simmed.
  • Each row is ranked by its better gear set; the two bars share that role's leader as their 100% reference so you can read both the ranking and the gap between the sets.
  • AoE numbers are raw target damage — funnel, priority-target cleave, burst windows and utility, much of what decides real Mythic+ strength, are not represented. Treat this as throughput potential, not a meta ranking.
  • Tanks are ranked separately and only by damage output; survivability is not simulated.
  • Within each tab, tier letters (S through F) group specs relative to each other rather than by a fixed gap from the leader: we cluster the specs on their sim DPS by natural breaks (1-D k-means), the same method the home page uses for its tier lists, then label the clusters best-first. So a tier collects specs of comparable throughput, and the “Behind #1” column still shows each spec's exact gap to the leader.
